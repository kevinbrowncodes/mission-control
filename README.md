# Mission Control

A macOS menu bar utility that provides quick access to Mission Control.

## Goal

The primary goal of this project is to create a lightweight menu bar application that, when clicked, instantly triggers macOS Mission Control. This provides an alternative way to access Mission Control for users who prefer mouse-based interactions or want a visible shortcut.

## Usage

1. Launch the application.
2. A new icon will appear in your macOS menu bar.
3. Click the icon to activate Mission Control.

## Development

This project is built using SwiftUI and AppKit.

### Requirements

- macOS 13.0+ (Ventura or newer recommended)
- Xcode 14.0+

### Building from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/kevinbrowncodes/mission-control.git
   ```
2. Open `MissionControl/MissionControl.xcodeproj` in Xcode.
3. Build and Run (Cmd + R).
